ClipNote Privacy Policy

Last updated: August 2026

ClipNote helps users create annotations, notes, and summaries from web content.

Information We Collect

ClipNote may collect:

  • Email address and account information for user authentication.
  • User-created annotations and comments.
  • Text selected by users for annotation.
  • Source information such as webpage URLs and titles.
  • AI-generated summaries when users request AI features.

How We Use Information

  • Provide annotation and note-taking features.
  • Save and synchronize user content.
  • Create user profiles.
  • Generate AI summaries when requested.

Website Access

ClipNote only accesses webpage information when users interact with the extension and choose to create an annotation. ClipNote does not collect general browsing history.

Data Sharing

ClipNote does not sell user data. Information is only shared with service providers needed to operate the application.

Data Security

We take reasonable measures to protect user information.
